# Data

The CantoNLU datasets were not committed to our repository. You can clone it from the source repository.

## How to get the data

From the repository root:
```bash
git clone https://github.com/Aatlantise/canto-nlu.git data/canto-nlu
cd data/canto-nlu && git checkout 2283874
```
